# Feature Ideas

## Order Experience

- [ ] Order status screen — public display showing order numbers being prepared and ready for pickup
- [ ] Order notes — free-text field per order for special requests
- [ ] Item images — photo thumbnails on menu items
- [ ] Favorites/popular items — highlight most-ordered items at the top

## Kitchen

- [ ] Sound notifications — audible alert on new orders (especially rush)
- [ ] Estimated prep time — configurable per item, shown on kitchen and status screen
- [ ] Order age timer — live counter showing how long each order has been waiting

## Admin

- [ ] Daily summary export — download CSV/PDF of orders and revenue
- [ ] Scheduled menu — different menus for different days of the week
- [ ] Item availability count — stock quantity instead of just sold out toggle
- [ ] Multi-day stats — revenue/order charts over time
- [ ] Bulk price update — adjust prices for an entire category at once

## General

- [ ] Multi-language support — UI language toggle (German/English)
- [ ] PWA / installable app — add to homescreen with offline shell for tablets
- [ ] Receipt printing — thermal printer integration for order confirmations
- [ ] QR code self-order — customers scan a QR and order from their phone
